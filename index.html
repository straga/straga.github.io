letapis AI

Search and memory over your code and documents, asked by meaning instead of grepped by hand. One query finds where something is handled, who calls a symbol, and what was decided about it last week. It runs as an MCP server, so AI coding agents stop re-reading the repository from scratch on every session.

letapis.ai · documentation

AI farm

A small farm of AI coding agents doing real engineering: each head has a role — planning, writing, reviewing, testing — and they pass work to each other through a shared registry, documentation and long-term memory. Not a demo: it ships the products on this page.

Hardware

A compact AMD Strix Halo box with unified memory runs local language models and our self-hosted services — including the machine that runs letapis itself. Tuning one small machine to do the work of a rack.
